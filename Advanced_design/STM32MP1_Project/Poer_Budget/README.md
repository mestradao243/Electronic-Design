#Español

El **Power Budget** define y documenta los principales consumidores de energía del sistema, considerando los diferentes bloques y periféricos que componen el computador basado en la **STM32MP1**. Se incluyen la MPU, memoria DDR, PMIC, Ethernet, display, interfaces USB OTG/Host, almacenamiento eMMC, entradas de alimentación mediante DC Barrel y USB-C, así como los pines y botones destinados a funciones de debug y boot. El objetivo es proporcionar una referencia para estimar y verificar los requerimientos de alimentación del sistema bajo diferentes condiciones de operación.


#English

The **Power Budget** defines and documents the main power consumers of the system, considering the different blocks and peripherals that make up the computer based on the **STM32MP1**. It includes the MPU, DDR memory, PMIC, Ethernet, display, USB OTG/Host interfaces, eMMC storage, DC Barrel and USB-C power inputs, as well as pins and buttons intended for debug and boot functions. The goal is to provide a reference for estimating and verifying the system's power requirements under different operating conditions.
